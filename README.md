# SuperDuckSystem

SuperDuckSystem is the custom gameplay platform for QDucks SMP.

- Target: Paper 1.21.11
- Java: 21
- Build: Gradle Kotlin DSL
- Database: SQLite
- Development branch: `dev`

The long-term system includes configurable economy, Ducks currency, shop/sell, auctions, orders, keys/crates, settings, stats, leaderboards and Duck custom tools. Infrastructure such as permissions, world protection, rollback, RTP and crossplay remains handled by mature external plugins.

See [`docs/ROADMAP.md`](docs/ROADMAP.md) and [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
